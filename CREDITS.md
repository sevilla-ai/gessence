# CREDITS

## Toolchains

- **GNAT Ada toolchain**  
  Used to compile the Ada source and manage the `gessence.gpr` project for native and WebAssembly targets.

  Used or planned for compiling the core resolver into `.wasm` artifacts for browser execution.
